# Dataset

**Source**: [Food.com Recipes and Interactions](https://www.kaggle.com/datasets/shuyangli94/food-com-recipes-and-user-interactions) (Kaggle)
~180K recipes, ~700K user interactions. See the project blueprint (`01_recipe_ai_project_blueprint.md`) §4 for why this dataset was chosen over RecipeNLG, Epicurious, and the Yummly ingredients dataset.

## Getting the real data

```bash
pip install kaggle
# Get an API token: kaggle.com/settings -> "API" -> "Create New Token"
# This downloads kaggle.json - place it at ~/.kaggle/kaggle.json (chmod 600)

kaggle datasets download -d shuyangli94/food-com-recipes-and-user-interactions
unzip food-com-recipes-and-user-interactions.zip -d data/raw/
```

You should end up with these two files:
```
data/raw/RAW_recipes.csv
data/raw/RAW_interactions.csv
```

## Development sample

This repo currently ships with a small (~300 recipe) **schema-accurate
synthetic sample** in `data/raw/`, generated by
`ml/data/make_sample_dataset.py`. It exists because the development
sandbox used to build this pipeline could not reach kaggle.com — every
column name and value format (stringified Python lists for ingredients/
steps/tags/nutrition, the same nutrition field ordering, etc.) matches
the real dataset exactly, so **no downstream code changes** when you
swap in the real files. Just replace the two CSVs and re-run:

```bash
python ml/data/make_sample_dataset.py   # (skip this if using the real data)
python notebooks/_build_eda_notebook.py # regenerates and re-executes the EDA notebook
```

Everything downstream (`clean_recipes`, the vocabulary, the train/val/test
split, and eventually model training) was built and unit-tested against
this sample and is expected to work unmodified at full scale — the main
things worth re-checking once the real data is in are the vocabulary size
and the `estimate_difficulty` thresholds in `ml/config.py`, both of which
were calibrated against the sample's (much smaller, more uniform)
distribution and are explicitly flagged for review in `01_eda.ipynb` §3 and §4.
